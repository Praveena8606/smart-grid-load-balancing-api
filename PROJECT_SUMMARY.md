# Smart Grid Load Balancing API

## Objective

To monitor electricity load distribution across sectors and identify overload conditions in a smart grid environment.

## Features

* Health Monitoring
* Load Management
* Alert Generation
* Dashboard Analytics
* Grid Status Monitoring
* Load Prediction
* Smart Recommendations

## Technologies Used

* Python
* FastAPI
* SQLAlchemy
* SQLite
* Uvicorn

## API Endpoints

### GET /health

Checks API status.

### POST /load

Adds new load data.

### GET /loads

Returns all load records.

### GET /alerts

Shows overloaded sectors.

### GET /dashboard

Returns dashboard statistics.

### GET /grid-status

Returns overall grid health.

### GET /prediction

Predicts future load.

### GET /recommendations

Provides recommendations for load balancing.
